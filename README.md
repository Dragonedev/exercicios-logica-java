Cada exercício é representado por uma classe separada.  
Exemplo: `Ex01MaiorNumero.java`, `Ex02SomaMedia.java`, etc.

---

## 📋 Lista de Exercícios

| Exercício | Descrição |
|-----------|-----------|
| `Ex01MaiorNumero` | Lê dois números e exibe o maior |
| `Ex02SomaMedia` | Calcula soma e média de três notas |
| `Ex03ParOuImpar` | Verifica se um número é par ou ímpar |
| `Ex04TrocaTresValores` | Realiza a troca circular entre A, B e C |
| `Ex05Aposentadoria` | Checa se a idade já permite aposentadoria |
| `Ex06SalarioBonus` | Calcula salário com bônus (condicional) |
| `Ex07ConversaoTemperatura` | Converte °C para °F |
| `Ex08AreaCirculo` | Calcula área de um círculo com base no raio |
| `Ex09Tabuada` | Exibe a tabuada de um número desejado |
| `Ex10MultaVelocidade` | Calcula multa por excesso de velocidade |
